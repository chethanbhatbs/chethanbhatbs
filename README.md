### What I do

I'm a QA Engineer at [Emergent](https://emergent.sh) focused on **evaluating AI coding agents** — the hard parts of QE that don't fit a Jest suite. My day-to-day:

- **Job-level evals** — phase-by-phase analysis of agent runs (trajectories, costs, HITL turns, ECU breakdowns)
- **Model & template comparisons** — template-vs-scratch, Opus 4.6 → 4.7, GPT-5.5 routing, cost forensics
- **Production debugging** — Temporal Cloud (`production.urgaq`), MongoDB, Redash, pod-level log diving
- **Tooling** — Claude Code skills and internal scripts to make eval work repeatable instead of artisanal

Off the clock, I build small full-stack apps and Chrome extensions.
